# easyVerein API-Samples

Der hier zur Verfügung gestellte Code dient lediglich der Einarbeitung in die [REST-API von easyVerein](https://easyverein.com).

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

In allen Beispielen muss `<YOUR-API-KEY>` durch einen eigenen API-Schlüssel ersetzt werden. Den Schlüssel erzeugt man in easyVerein unter Einstellungen → easyVerein API. Ab v2.0 der API muss er nach einer bestimmten Zeit erneuert werden, ein Beispiel dafür gibt es [hier](Python3/API_v3_0/refresh_token.py).

## Inhalt

- `Python3/API_v3_0` und `Python3/API_v2_0`: Beispiele für die jeweilige API-Version
- `Bash`, `PHP`, `JavaScript`: einzelne Anfragen in anderen Sprachen
- `ExampleJSONs`: Beispiel-Daten für Anfragen

Was sich zwischen v2.0 und v3.0 geändert hat, steht in den [easyVerein-API-Integration-Guides](https://github.com/SD-Software-Design-GmbH/easyVerein-API-Integration-Guides).
